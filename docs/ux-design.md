# 琉璃 Launcher UX 設計（v2）

> 2026-11-08。取代 v1 的「網頁桌布」方向：以**流暢**為第一優先，視覺改為真正的 Liquid Glass。原型：[design/prototype.html](../design/prototype.html)（用瀏覽器開啟，下方按鈕可切換桌布、側邊面板與焦點）。

## 1. 為什麼 v1 感覺「像被鎖 FPS」

不是單一卡頓，而是**每一幀都在做太多事**，讓動畫幀率掉到 20～40fps，看起來就像被限制了：

| 原因 | 影響 |
|---|---|
| 網頁桌布（WebView）一直在跑 canvas 動畫 | 跟主畫面搶 GPU；電視晶片同時合成兩層全螢幕畫面很吃力 |
| 每 2.5 秒在主執行緒把 WebView 畫進點陣圖（給玻璃用） | 每次都會讓 UI 停頓一下 |
| 每個玻璃面板每一幀都做即時模糊（RenderEffect blur） | 模糊是電視 GPU 最貴的運算之一 |
| 原生流動桌布無限動畫 | 讓所有模糊面板每一幀都要重算 |
| 焦點動畫在「組合」階段讀取動畫值 | 每一幀都重新組合整個圖塊 |
| 所有 App 圖塊一次全部組合（非 Lazy） | 圖塊多時捲動吃力 |
| Release 版沒有開 R8、沒有基準設定檔 | Compose 官方明確指出，未經 R8 最佳化的 Compose 會明顯變慢，首次動畫也會因 JIT 編譯而掉幀 |

### Flutter 會比較好嗎？

**不會根本改善。** 上面每一項換到 Flutter 一樣存在（Flutter 的 `BackdropFilter` 一樣是逐幀模糊，WebView 在 Flutter 裡還要額外走 PlatformView，更慢）。Flutter 在低階電視晶片上也沒有比 Compose 快，而且遙控器焦點、無障礙、系統整合都要多繞一層。正確做法是**拿掉每幀的昂貴工作**，Compose 在同樣的電視上可以穩定 60fps。

## 2. 效能預算（v2 的規則）

1. **每幀零模糊運算**：桌布是靜態圖，啟動時（或每天換色時）**只模糊一次**，玻璃面板直接取用模糊好的那張圖的對應區域，成本等於貼一張圖。
2. **只有焦點和捲動在動**：沒有無限動畫，畫面靜止時 GPU 閒置。
3. **動畫只動圖層屬性**（縮放、位移、透明度），在 RenderThread 處理，不重新組合、不重新排版。
4. **Lazy 清單**：只組合看得到的圖塊。
5. **R8＋資源縮減＋profileinstaller**：讓 Compose 內建的基準設定檔在安裝時預先編譯，第一次操作就順。
6. 側邊面板打開時，主畫面只做**一次靜態模糊**（Android 12 以上），面板滑入時只有面板本身在重繪。

## 3. 使用者需求整理

| 需求 | 頻率 | 設計回應 |
|---|---|---|
| 開常用 App | 每次 | 開機焦點就在常用列第一個；按一下確定就開 |
| 看時間 | 每次 | 左上大字時鐘，不需操作 |
| 看今天農曆、初一十五、節日 | 每天 | 時鐘下方一行農曆；「今日」卡片顯示宜忌與節日，拜拜日用暖色標示 |
| 看天氣、要不要帶傘 | 每天 | 右上天氣膠囊＋天氣卡片（降雨機率） |
| 查某天的農民曆 | 每週 | 今日卡片按確定 → 月曆頁 |
| 看未來幾天天氣 | 每週 | 天氣卡片按確定 → 天氣頁（逐時、7 日） |
| 切訊號源（PS5、第四台） | 依家庭 | 右上專用按鈕，一按出側邊面板 |
| 調整常用 App、隱藏不用的 App | 偶爾 | 長按確定鍵 → 側邊面板 |
| 系統設定、App 設定 | 偶爾 | 右上設定按鈕；長按 App →「應用程式資訊」 |
| 遙控器按鍵改綁、防止回原廠主畫面 | 設定一次 | 設定 → 遙控器按鍵 |

## 4. 資訊架構

```
主畫面
├─ 頂列：時鐘＋日期農曆（左）｜天氣膠囊・訊號源・設定（右）
├─ 小工具：今日（農民曆）卡 → 月曆頁 ｜ 天氣卡 → 天氣頁
├─ 常用列（玻璃層架）
└─ 所有應用程式（往下捲）
側邊面板（從右側滑入的玻璃面板）：訊號源、設定、App 選項、各種子選單
月曆頁：月檢視＋所選日期的農民曆詳情
天氣頁：現在、逐 3 小時、7 日預報
```

## 5. 焦點模型（遙控器）

- 開機與按 Home：焦點回到常用列第一個 App。
- 上下鍵在「頂列按鈕 → 小工具 → 常用列 → App 格線」之間移動；每一列記住上次的位置（`focusRestorer`）。
- 返回鍵：側邊面板 → 關閉；子頁面 → 回主畫面；主畫面 → 捲回頂端（不離開）。
- 長按確定鍵（約 0.5 秒）＝更多選項，畫面下方有提示文字。
- 焦點效果：放大 1.08 倍＋白色描邊＋陰影＋斜向光澤，彈簧動畫（阻尼 0.8、偏硬，跟手不拖泥帶水）。只有焦點中的 App 顯示名稱，畫面保持乾淨。

## 6. 視覺語言：Liquid Glass

| 元素 | 做法 |
|---|---|
| 桌布 | 程式產生的同色系抽象漸層＋流線色帶（色帶的銳利邊緣讓玻璃後的模糊看得出來）。四組配色：深海、暮光、晴空、夜林；預設「依時間自動」：白天晴空、傍晚暮光、晚上深海 |
| 玻璃 | 預先模糊（約 22dp）＋飽和度 1.4 的桌布 → 白色 7% 透明疊色 → 上緣高光 → 下緣反光 → 1dp 玻璃厚度邊 → 邊緣內光 → 外陰影 |
| 折射 | Android 13 以上用 AGSL 著色器做邊緣透鏡折射（靠近邊緣的背景往內彎），較舊的電視自動略過 |
| 文字 | 時鐘 Thin 76sp；標題 Medium；內文 Regular；次要資訊 70% 不透明 |
| 強調色 | 只用一個：暖金色（#FFD99A），用在節氣、節日、拜拜日 |
| 圓角 | 面板 26～34dp、按鈕全圓、App 圖塊 18dp |
| 安全區 | 左右 48dp、上下 28dp（電視過掃描） |

**避免俗氣的規則**：桌布只用一個主色相＋鄰近色；畫面上的彩色只來自桌布和 App 圖示，UI 本身只有白色與一個暖金強調色；不用彩色按鈕、不用漸層文字、不用發光外框。
