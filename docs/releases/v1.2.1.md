# 琉璃 Launcher 1.2.1

為 Google TV／Android TV 打造的主畫面：玻璃質感、跟著焦點流動的背景、內建農民曆，流暢第一。

## 修正

- 軟體更新修好了：之前按「安裝新版本」後會一直停在「交給系統安裝中…」，系統的確認畫面不會出現；現在會正常打開系統安裝畫面

## 改變

- 設定 → 關於琉璃 只留一列「軟體更新」，從頭到尾都在同一列按確定：檢查（顯示下載進度）→ 有新版時變成「更新到 x.y.z」並列出重點 → 再按一次交給系統安裝
- 第一次更新時，系統會先請你允許琉璃安裝 App；畫面上會說明允許後按返回、再按「安裝」
- 系統畫面 20 秒沒出現可以在同一列再按一次；取消或失敗會說明原因並可重試
- 更新完成、琉璃重新開啟後，會顯示「已更新到 x.y.z」

## 注意

1.1.x 與 1.2.0 的「安裝新版本」有上面的問題，從這些版本更新到 1.2.1 需要手動安裝一次（下載下方 APK 覆蓋安裝，設定會保留）；之後的版本就可以在電視上直接更新。

## 安裝

下載下方的 `LiuliLauncher-1.2.1.apk`，可以直接覆蓋安裝 1.0.0 以後的版本，設定會保留。詳細步驟見 [README](https://github.com/candy999/liuli-launcher#安裝)。
