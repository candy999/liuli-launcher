# 琉璃 Launcher 1.2.2

為 Google TV／Android TV 打造的主畫面：玻璃質感、跟著焦點流動的背景、內建農民曆，流暢第一。

## 新功能

- 所有 App 最後一格是「顯示系統應用」：按下去後系統應用接在同一個格子裡展開，可以直接捲動、開啟；再按「隱藏系統應用」或關掉抽屜就收起來

## 改變

- 天氣詳細頁、農民曆詳細頁也換成和主畫面一樣的霧玻璃焦點與布丁般的彈性：從按的方向帶過來、到底撞牆；打開頁面時同樣用彈簧浮上來

## 修正

- 設定側邊欄（包含每一個子選單）在第一列往上、最後一列往下按時，選中的那一列不再被上下邊緣切掉
- 農民曆往上或往下跨月時，選中日期的框不再被切到；週六、週日那兩欄和平日被切的位置不同的問題一起修好

## 安裝

已安裝 1.2.1 的電視：設定 → 關於琉璃 →「軟體更新」按確定，有新版時再按一次安裝。

1.2.0 以前的版本更新功能有問題，需要下載下方的 `LiuliLauncher-1.2.2.apk` 手動覆蓋安裝一次，設定會保留。詳細步驟見 [README](https://github.com/candy999/liuli-launcher#安裝)。
