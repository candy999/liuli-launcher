# 琉璃 Launcher 1.0.0（第一個穩定版）

第一個穩定版。已在 AOC 4K 電視（Realtek RTD6748、PowerVR BXE-4-32、Android 11、1.7 GB RAM）完整驗收，並在 MEmu 模擬器（Android 9）測試。

## 重點

- **主畫面**：時間＋農曆＋時辰＋初一十五提示＋宜忌、天氣、網路狀態、訊號源、常用 App、所有 App 抽屜；文字直接放在背景上，選到才浮出玻璃
- **跟著焦點流動的背景**：App 主題色＋電容式緩衝，12 種向量背景樣式
- **液態玻璃**：高斯模糊＋過曝，沒有框線
- **農民曆**：子時（23:00）換日、時辰、吉時、宜忌、沖煞、節氣、台灣節日；全部正體中文（1901～2099 逐日稽核）
- **月曆**：方向鍵選日期、自動翻月；宜忌最多的一天也完整顯示
- **天氣**：Open-Meteo，逐 3 小時與 7 日預報，手動選縣市
- **邊框**：黑框粗細、圓角、漸變範圍，原生解析度繪製，只蓋背景與捲動列
- **App 管理**：加入／移除常用、抓住後左右移動位置、顯示或隱藏手機版 App
- **遙控器**：任何按鍵短按／長按改綁、受保護的基本鍵、主畫面保護、內建網路 ADB 自己開啟按鍵服務
- **流暢度**：操作時背景自動省力、自適應解析度（原生 ÷1～÷5）與更新率、停止前提前對焦、慢速播放；靜止時零重畫
- **新 Logo**：浪中琉璃——一塊磨砂玻璃 App 磚半浸在釉色浪潮裡

## 1.0.0 前最後修正

- 常用全部移除後打不開所有 App（改放「＋ 加入常用」磚）、移除常用後焦點跳到時鐘
- 簡體字殘留（餘事勿取、行喪、掛匾、造橋、開廁、斷蟻、僱傭、閏月）
- 農曆日改以子時換日；月曆宜忌字數過多顯示不下
- 移動常用 App 時圖塊變形、所有 App 長按選單拿不到焦點
- 背景樣式效能：光軌 200ms → 12ms、絲綢、紙雕（陰影抖動）、等高線、極光

## 安裝與升級

下載下方的 `LiuliLauncher-1.0.0.apk`。從 0.1.x 預覽版升級時請先解除安裝（預覽版每次建置的簽章不同），設定需要重新設定一次。詳細步驟見 [README](https://github.com/candy999/liuli-launcher#安裝)。
