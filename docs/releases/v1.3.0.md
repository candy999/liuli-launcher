# 琉璃 Launcher 1.3.0

為 Google TV／Android TV 打造的主畫面：玻璃質感、跟著焦點流動的背景、內建農民曆，流暢第一。

## 新的背景樣式

背景樣式從 12 種增加到 23 種，選單依關聯性分組排序（夜空與光、光點與光軌、線條與幾何、色彩與流體、單色）。

- **由顯示晶片（GPU）繪製**，選單右邊有晶片圖示：
  - **柔極光**：暗色天空上三條柔和的極光帶起伏飄動
  - **極光簾**：極光的簾腳彎曲起伏，往上透出帶細絲的光幕
  - **漸層百葉**：一排直立的百葉片，朝向焦點的那一側亮起
  - **網格漸層**：幾團顏色沿著各自的軌跡流動、互相暈染，最亮的那團跟著焦點
  - **色塊雜訊**：幾種顏色像地圖色塊一樣分層，慢慢流動
  - **扭曲色帶**：幾種顏色被一層層漩渦扭成柔和流動的色帶
  - **水彩暈染**：焦點換到哪，就在那裡滴下一滴顏料慢慢暈開，乾掉的水痕顏色較深
  - **液態以太**：流體模擬，焦點移動時把彩色的流體推開，閒置時輕輕攪動
- **螺旋**：一條螺旋線繞著焦點慢慢轉
- **特魯謝緞帶**：隨機拼接的圓弧連成蜿蜒的緞帶，整片慢慢捲動
- **三色濃醬**：巧克力、焦糖、奶油三色交錯，焦點是攪拌的中心，越靠中心捲得越多；移過去時舊的捲紋慢慢鬆開

## 流暢度與畫質

- 顯示晶片繪製的樣式依電視實際的效能自動調整解析度（原生到五分之一）：閒置時盡量升到最清楚的畫質，操作中、面板打開時先讓給介面
- 針對只支援半精度運算的顯示晶片（例如海信 Mali-470）重寫計算方式，色帶與色塊的邊緣不再起毛、一階一階；支援全精度的晶片自動改用全精度
- 這台電視的顯示晶片畫不了某個樣式時，自動改由處理器繪製，選單上的晶片圖示也會拿掉
- 毛玻璃依負載自動決定每秒更新幾次（最多用掉一個核心的八成）；更新得慢時新舊兩張交叉淡化，看起來是順的
- 背景優先於毛玻璃：背景跟不上時，先減少毛玻璃的更新次數，到最低了才降背景的畫質

## 修正

- 打開側邊欄時，技術宅模式狀態列的毛玻璃亮度會抖動、看起來像失效：主畫面退後改成蓋一層暗色，毛玻璃保持霧面
- 收起來的所有 App 抽屜不再跟著背景換色一直重畫

## 安裝

已安裝 1.2.1 以後版本的電視：設定 → 關於琉璃 →「軟體更新」按確定，有新版時再按一次安裝。

1.2.0 以前的版本更新功能有問題，需要下載下方的 `LiuliLauncher-1.3.0.apk` 手動覆蓋安裝一次，設定會保留。詳細步驟見 [README](https://github.com/candy999/liuli-launcher#安裝)。
