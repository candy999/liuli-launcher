# 琉璃 Launcher 1.2.3

為 Google TV／Android TV 打造的主畫面：玻璃質感、跟著焦點流動的背景、內建農民曆，流暢第一。

## 改變

- 所有 App 抽屜、設定側邊欄開關更順：打開時空的玻璃框先彈上來，App 和設定列再一排一排出現；收起時整塊一起收下去，收到一半主畫面才開始淡入
- 天氣頁、農民曆頁進出時改回原本的淡入與輕微上浮，果凍彈性只留在頁面裡移動選取的時候
- 開著琉璃的按鍵服務時，打開抽屜、移動焦點不再定時卡一下

## 修正

- 從訊號源往上移到時鐘時，時鐘的玻璃中間不再閃一條橫線
- 農民曆往上或往下跨月時，選中日期的框不再被切到（1.2.2 還有部分情況會被切）
- 設定側邊欄彈出時，選中的那一列左右兩端不再被切掉一瞬間
- 抽屜彈出到定位那一下，兩側不再閃一條黑線；打開抽屜時，常用列焦點那一格不再留下一個深色方框

## 安裝

已安裝 1.2.1 以後版本的電視：設定 → 關於琉璃 →「軟體更新」按確定，有新版時再按一次安裝。

1.2.0 以前的版本更新功能有問題，需要下載下方的 `LiuliLauncher-1.2.3.apk` 手動覆蓋安裝一次，設定會保留。詳細步驟見 [README](https://github.com/candy999/liuli-launcher#安裝)。
