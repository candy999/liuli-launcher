# 琉璃 Launcher 1.1.1

為 Google TV／Android TV 打造的主畫面：玻璃質感、跟著焦點流動的背景、內建農民曆，流暢第一。

## 修正

- 看 YouTube、切換訊號源時，琉璃在背景仍在計算閒置時間，按 Home 回來會直接進入簡潔模式（開著「自動清理記憶體」時還會清理一次）。現在只在琉璃停在主畫面時計時，回到主畫面從頭開始計時；技術宅模式的系統取樣也只在主畫面顯示時進行

## 這個版本有什麼

- **主畫面**：時間、日期、農曆、時辰、初一十五提示、今日宜忌；天氣與明天提醒；網路狀態、設定；訊號源、常用 App，按下鍵展開所有 App。文字直接放在背景上，選到才浮出玻璃
- **兩種主畫面模式**（設定 → 主畫面模式）
  - 正常人模式：乾淨的主畫面
  - 技術宅模式：齒輪下方的火箭一鍵清理背景程式（畫面中央 3 秒顯示釋放多少記憶體）；常用列下方五張即時儀表——CPU（型號、使用率、各核心）、GPU（型號、fps、每幀時間）、記憶體、網路（Wi-Fi／有線／未連線、延遲、抖動、流量）、系統（電視品牌型號、開機時間、IP、儲存空間）
- **12 種背景樣式**，第一個是**隨機**：每次啟動從你勾選的樣式裡換一個
  - **玉山星軌**：向量平塗的玉山分成七層，焦點移動時有視差；山的光影跟著一天的太陽走（12 個時段），暗面帶一點焦點 App 的色系；山谷間的霧由左往右流動；星軌整天繞著南天極轉，深夜是長曝光色調
  - 等高線、流線浪潮、深海、星空銀河、光束、光軌、光斑、波點圓圈、幾何三角、純色、純黑
- **時光**（設定 → 外觀 → 時光）：會隨時間變化的背景用實時，或固定在一個模擬時刻
- **背景跟著焦點變色**，也可以固定一個顏色；背景模糊、細緻噪點、邊框
- **簡潔模式**：只留時間與天氣；閒置自動進入、微光、微飄移防烙印，可設定進入時自動清理記憶體
- **農民曆與月曆**：子時換日、時辰、吉時、宜忌、沖煞、節氣、台灣節日，全部正體中文
- **天氣**：逐 3 小時與 8 日預報，手動選縣市
- **App 管理**：加入／移除常用、移動位置、顯示或隱藏手機版 App
- **螢幕小時鐘**：看其他 App 時角落仍然看得到時間
- **遙控器按鍵**：任何按鍵短按／長按改綁、主畫面保護
- **流暢度**：背景解析度依每一幀的實際耗時自動調整；玉山星軌的山與星軌以原生解析度顯示，焦點停下來就是最清楚的畫面
- **冷啟動**：背景等樣式資源準備好，才從焦點所在的位置往外擴散
