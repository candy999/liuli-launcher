# 琉璃 Launcher 1.3.1

為 Google TV／Android TV 打造的主畫面：玻璃質感、跟著焦點流動的背景、內建農民曆，流暢第一。

## 修正

- 電視關機再開機（或待機喚醒）後，顯示晶片繪製的背景（例如扭曲色帶）只畫在左下角一小塊、其他地方全黑：現在一律鋪滿整個畫面
- 背景每隔一段時間會突然跳一下（扭曲色帶、色塊雜訊、水彩暈染約二三十分鐘一次，柔極光、網格漸層更頻繁）：所有持續流動的背景改成無縫循環，可以一直開著
- 主畫面連續開好幾天之後，背景的流動可能變得一頓一頓：一併修正

## 改進

- 扭曲色帶在只支援半精度運算的顯示晶片（例如海信 Mali-470）上，色帶對折處的細線不再一節一節像鋸齒
- 開了別的 App 時，背景在看不到的時候自動重整，回到主畫面從頭開始；回來時毛玻璃也馬上換成目前背景的顏色

## 安裝

已安裝 1.2.1 以後版本的電視：設定 → 關於琉璃 →「軟體更新」按確定，有新版時再按一次安裝。

1.2.0 以前的版本更新功能有問題，需要下載下方的 `LiuliLauncher-1.3.1.apk` 手動覆蓋安裝一次，設定會保留。詳細步驟見 [README](https://github.com/candy999/liuli-launcher#安裝)。
